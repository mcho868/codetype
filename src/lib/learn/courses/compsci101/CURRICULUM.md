# Python Essentials — Principles of Programming

**Level:** Beginner · **Duration:** 10 Weeks · **Language:** Python 3

A hands-on introduction to programming. Every week pairs short, focused lessons with an
interactive in-browser code editor. You write real Python; a backend test runner grades your
solutions against hidden test cases — the same "CodeRunner" style used in university courses.
Each week ends with a short timed **Test** to consolidate and stretch your understanding.

## How the Course Works

- **Learn** — each week has 4–6 lessons with explanations and runnable code examples you can edit and execute in the browser.
- **Practice** — most questions are coding challenges. You write a function or a program; the backend runs it against visible *sample* cases plus *hidden* edge cases and reports pass/fail.
- **Test** — after each week, a short timed test (~6 questions) with harder, synthesis-style problems. Tests are optional and do not block progress; their detailed explanations turn any miss into a lesson.
- **Concept checks** — a small number of multiple-choice / true-false / fill-in-blank questions reinforce key ideas (errors, types, mutability, return vs print, and more).

## Detailed Outline

### Week 1 — Foundations & Simple Data
Start your Python journey: what algorithms are, how Python runs code, literals, operators, expressions, variables, assignment, and printing output with `print()`.
- Set Up Python on Your Computer
- What Is an Algorithm?
- Literals, Operators & Expressions
- Variables & Assignment
- `print()` & Errors

### Week 2 — Input & Output, Types
Read user input with `input()`, work with int/float/str, format output with f-strings, and write clear comments and docstrings.
- Input and Output
- Types: int, float, and str
- Working with Numbers
- f-strings
- Comments, Docstrings, and Style

### Week 3 — Conditions
Make decisions with `if/elif/else`, booleans, logical operators, chained comparisons, floats in conditions, and nested branches.
- if, elif, and else
- Booleans & Comparison Operators
- Logical Operators
- Chaining Comparison Operators
- Floats in Conditions
- Nested Conditions

### Week 4 — while Loops
Repeat code with `while` loops, build accumulators, read until a sentinel value, and validate user input with loops.
- while Loops
- Accumulators
- Sentinel Loops
- Input Validation
- Loop Patterns & Pitfalls

### Week 5 — Sequences: Strings & Lists
Work with ordered sequences: string and list indexing, slicing, substrings, sublists, and the difference between mutable lists and immutable strings.
- Indexing & Slicing
- Substrings
- List Basics
- Sublists
- Mutable vs Immutable

### Week 6 — String & List Methods
Master built-in string methods (`upper`, `lower`, `split`, `join`, `replace`, `find`) and list methods (`append`, `extend`, `pop`, `sort`, `count`) with practical worked examples.
- upper() and lower()
- split() and join()
- replace() and find()
- append(), extend(), and pop()
- sort() and count()

### Week 7 — for Loops & range()
Repeat work with `for` loops over strings and lists, process text character by character, and generate sequences with `range()` in one-, two-, and three-argument forms.
- for Loops Over Strings
- for Loops Over Lists
- Text Processing with for
- range() — One Argument
- range() — Two & Three Arguments

### Week 8 — Functions
Define and call functions, pass parameters, return values, break problems into smaller pieces with decomposition, and build tic-tac-toe helper functions.
- Defining and Calling Functions
- Parameters and Arguments
- Return Values
- Decomposition
- Tic-Tac-Toe Helpers

### Week 9 — Tuples & Files
Work with immutable tuples, multiple assignment, lists of tuples for structured data, and read, write, and append text files (simulated via string parameters in exercises).
- Tuples
- Multiple Assignment
- Lists of Tuples
- Reading & Writing Files

### Week 10 — Dictionaries & Nested Loops
Create and update dictionaries, iterate keys/values/items, build frequency counts, and process nested lists and 2D grid data with nested loops.
- Dictionary Basics & CRUD
- Iterating Dictionaries
- Frequency Counts
- Nested Lists & 2D Data
- Combining Dicts & Nested Loops

## Learning Outcomes

By the end of the course you will be able to:

- Read and trace Python programs, and distinguish syntax errors from runtime errors.
- Use variables, expressions, and the core data types (`int`, `float`, `str`, `bool`).
- Read input and format output clearly, including with f-strings.
- Control program flow with conditions and both `while` and `for` loops.
- Work confidently with strings, lists, tuples, and dictionaries, and their built-in methods.
- Decompose a problem into functions with parameters and return values.
- Process structured and 2D data with nested loops.
- Write, run, and debug your own Python programs.
