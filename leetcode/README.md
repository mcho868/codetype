## LeetCode Solutions

Actual standalone solution files live here instead of the project root.
These files are generated from the Python and TypeScript code examples in
`src/lib/learn/courses/leetcode/questions/`.

Structure:

- `binary-search/` for binary search and rotated-array problems
- `stack/` for stack-based problems
- `arrays-hashing/` for arrays and hashing problems
- `two-pointers/` for two-pointer problems

See `manifest.txt` for the current generated file list and source-module mapping.
